This folder contains scripts related to data wrangling tasks, including data cleaning, transformation, and preparation for analysis.

- `01_wrangle_predictors.R`: extracts all predictors to groundwater well locations
- `02_conus_map_physical_predictors.R`: extracts non-PFAS source predictors to the 1-km resolution CONUS grid points
- `03_conus_map_point_source.R`: calculates distances to CONUS grid points for all PFAS contamination source predictors
